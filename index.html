          How it works

          Why it’s fast

          This page is one small HTML file and one script, with no framework and nothing to download before it can draw.

          • Instant first view. The last snapshot is kept in your browser, so a return visit shows numbers straight away and then refreshes them.
          • Light drawing. Charts and the map are drawn on canvas, the map is built into the page, and the table only draws the rows you can see.
          • Polite polling. Updates pause when the tab is hidden and back off if a source is struggling.
          • Straight to the chain. New blocks, masternodes and epochs come from public XDC RPC, with automatic failover between endpoints.

          Sources

          Where the numbers come from

          • Nodes, propagation and the 40-block charts: the official XinFin stats server (stats1.xinfin.network), streamed live over the same websocket that xinfin.network and stats.xdc.network use. Only nodes that choose to report appear.
          • Latest blocks, masternodes and epochs: public XDC RPC (rpc.plugin.global/xdcmainnet). Epochs are 900 blocks.
          • Price: CoinGecko, refreshed every minute.
